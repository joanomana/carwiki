
# Welcome to CarWiki 👋  
![Version](https://img.shields.io/badge/version-0.1.0-blue.svg?cacheSeconds=2592000)

> **CarWiki** is a responsive web application that integrates the [CarQuery API](https://www.carqueryapi.com/) to display categorized automotive data. Users can explore vehicles by brand, type, fuel, or popularity, view detailed specifications, and leave reviews.

## 🚀 Features

- 🔍 Filter and browse cars by categories (e.g., SUV, sport, fuel type)
- 🏷 View details of each model using SweetAlert
- 🏎 Explore top brands and their vehicles
- 🌟 Add reviews and ratings (stored locally)
- 📱 Mobile-friendly design with Flicking carousel navigation

## 📦 Tech Stack

- **Next.js** (App Router)
- **React**
- **Tailwind CSS**
- **SweetAlert2**
- **@egjs/react-flicking**
- **CarQuery API**

## 📥 Installation

```bash
npm install
```

## 🔧 Usage

```bash
npm run dev
```

Then open your browser and go to [http://localhost:3000](http://localhost:3000)

## 🌐 CarQuery API

This project uses the [CarQuery API](https://www.carqueryapi.com/) to fetch real-time automotive data including:

- Car brands and models
- Fuel types
- Vehicle categories
- Specifications (year, engine, body type, etc.)
